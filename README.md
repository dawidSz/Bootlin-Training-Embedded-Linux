# Embedded Linux systemdevelopment Training thanks to Bootlin Open-Source materials

## About
This repository documents my learning sessions in subject: Embedded Linux system development.
The goal is not only to complete a training course, but to gain a practical understanding of Embedded Linux systems and to build a portfolio of projects, notes, and lab results.
The learning path is primarily based on Bootlin's Embedded Linux System Development (https://bootlin.com/training/embedded-linux/) training and its accompanying QEMU-based practical labs. Bootlin provides open source materials which are also uploaded to this repository. You can find there the training agenta (as it would be realized on-site with trainer), pressentation slides for lectures and laboratory excercises descriptions.

## Learning Objectives
By completing this journey, I aim to:

- Understand the architecture of Embedded Linux systems
- Build and use cross-compilation toolchains
- Understand the Linux boot process
Configure and use U-Boot
- Configure, compile and boot the Linux kernel
- Build Linux root filesystems from scratch
- Use BusyBox effectively
- Understand Device Tree concepts
- Work with Linux filesystems
- Cross-compile third-party applications and libraries
- Use Buildroot
- Develop and debug Embedded Linux applications
- Prepare for advanced topics such as Yocto and Linux driver development
